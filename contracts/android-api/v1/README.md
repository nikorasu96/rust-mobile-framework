# Android public Kotlin API contract v1

This directory defines the intended source and JVM surface of the first public Android AAR before
Kotlin source exists. The entire v1 API is one final class:

```text
RmfSurfaceHost(ViewGroup)
RmfSurfaceHost.close(): Unit
```

Construction and `close` may occur on any thread and must marshal Android work to main. `close`
is idempotent. The AAR never exposes JNI payload bytes, native pointers, partial generational
handles or internal bridge objects.

Run the design-time contract check from the repository root:

```text
python3 scripts/check_android_public_api.py
```

The public constructor avoids the extra `Companion` class and bridge symbols generated by a Kotlin
companion factory. The JSON descriptors are a reviewed design baseline, not compiler-generated ABI evidence. Once
Kotlin source exists, strict explicit-API compilation and `checkKotlinAbi` must validate the
compiled artifact; this manifest remains the ownership and compatibility policy.
